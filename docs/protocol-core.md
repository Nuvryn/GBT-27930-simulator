# 协议基础模块

## 配置与日志

采用已确认的 cJSON 和 EasyLogger。配置解析拒绝未知键、重复键、非法类型、不可表示的物理值及不完整 JSON。
文件不超过 64 KiB，JSON 嵌套不超过 32 层。角色和版本必须明确提供；其余字段使用显式默认值。
参数单位由键名给出：`_mv` 毫伏、`_ma` 毫安、`_mah` 毫安时、`_wh` 瓦时、`_degc` 摄氏度、`_ms` 毫秒。
充电电流配置为正的幅值，线上按负电流和 −400 A 偏移编码。

日志由协议线程格式化并写入 EasyLogger 的 64 KiB 异步环形缓冲区，平台独立线程负责控制台和文件 I/O。EasyLogger 自有配置位于 `app/logging/`；
文件所有权及实际 I/O 位于 `backends/support/<平台>/log_sink.c`。
默认开启文件保存，未指定路径时按平台本地时间生成 logs/YYYYMMDD_HHMMSS_纳秒_PID.log，独占创建避免覆盖。显式 log_path 继续支持指定路径。
文件开启失败、异步缓冲满、写入失败和关闭失败均导致非零退出；退出前排空缓冲并等待工作线程结束，关闭文件输出时不创建文件。

## 报文接口

`gb27930_codec` 显式读写字节及位，不使用结构体映射或主机字节序。
公开接口包括描述符查询、字段查询、物理值设置、负载编码及解码。
字段具有范围、默认值和精确分辨率；不可精确表示的配置拒绝窄化。
可选字段未提供时，解码结果通过 `available` 标明，不用默认值伪造接收数据。

当前表项为 CHM、BHM、CRM、BRM、BCP、CTS、CML、BRO、CRO、BCL、BCS、CCS、BSM、BMV、BMT、BSP、BST、CST、BSD、CSD、BEM、CEM。
本地整理稿称“23 种”，但逐项表格列出上述 22 种；实现按明确列出的报文，不臆造额外一种。
BRM 按已记录的勘误使用 49 字节；CCS 发送长度分别为 2015 的 8 字节、2023 的 7 字节。
CTS 使用可配置的 BCD 日期时间。可选单体电压、温度和预留数据使用有界数组。

## TP 适配

`j1939_tp` 将上游内部结构封装在不透明实例中，公开创建、完整负载发送、帧输入、周期推进、状态查询和重置。
所有内存在创建时分配；负载复制进入实例缓冲区，接收回调内的数据只在回调期间有效。
一次调用最多发送一个 DT 包，使用传入的单调毫秒时间，不阻塞等待。支持 9～1785 字节。

上游原样保留，继续负责 CM/DT 编码及接收存储。外层执行源/目的地址、DLC、长度与包数关系、序号、会话和 PGN 校验，
在上游缓冲区写入前拒绝非法数据。通用完成通知绕开上游内置应用 PGN 分发，不调用原始全栈 listener。
TX/RX 使用独立上游上下文；每个实例只对接一个配置对端。库的全局回调限制所有实例必须串行、不可嵌套调用。

发送 RTS 沿用上游的单包 CTS 窗口；接收窗口可配置，受对端 RTS 最大包数限制。
按等待状态分别执行 T1、T2、T3、T4；支持 CTS Hold、请求已发送包重发、Abort 和提前 ACK 忽略。
计时采用无符号差值处理回绕。BAM 和其他 J1939 应用层功能不在 GB/T 27930 适配范围内。
下层发送错误由外层保存并通过事件和返回值传播，不依赖上游无条件成功的 void 发送回调。

## 验证

`test_sim_core` 使用独立 BCL、BCP、CTS 字节向量，检查两版长度、配置拒绝路径、1785 字节 TP 传输、10 ms 调度下限、
T1～T4、时钟回绕、序号 0、截断帧、会话冲突、提前 ACK 及发送失败。
该测试无需 CAN 或真实等待。完整应用的 vcan 与实物验证另外执行；不声明完整 MISRA 或协议认证。
